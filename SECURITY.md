# Security Policy

## Supported versions

Security fixes target the latest published version of
`@shutterstock/p-map-iterable`. Users of older versions may need to upgrade
to receive a fix.

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/shutterstock/p-map-iterable/security/advisories/new).
Do not disclose vulnerabilities in public issues or pull requests before
maintainers have had time to assess and address them.

Include a description of the issue and its impact, affected versions or
commits, and steps to reproduce or a minimal proof of concept. Sanitize logs
and examples; do not include access tokens, secrets, or private user data.

Maintainers will assess reports and coordinate remediation and disclosure
with the reporter.
